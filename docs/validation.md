# Проверка версии

Проверено локально 11 сентября 2026:

- TypeScript без ошибок; production-сборка выполнена.
- Четыре основных вкладки и обе развилки намерения меняют соответствующий контент.
- Выбранный сервис передаётся в форму и параметр URL.
- Мультивыбор интересов, обязательный контакт, отдельное согласие.
- Реальный успешный POST записал заявки в локальную D1.
- Прерывание сети показало ошибку и сохранило введённые данные для повтора.
- Успех только после ответа сервера; ссылки на выбранные материалы работают.
- API отклоняет некорректные данные и межсайтовый POST.
- Логотип, шрифты и изображения загружаются; отсутствуют JS-ошибки.
- Нет горизонтального переполнения страницы при ширине 320, 390, 768 и 1440 px; ряд демонстрационных экранов на телефоне прокручивается внутри своего контейнера.
- Форма закрывается Escape; вкладки и диалог используют доступные примитивы Radix.
- WebMCP проверен в имитированном реестре браузера: корректный сервис открывает ту же форму, некорректный намеренно отклоняется. Интеграция с внешним агентом не проверялась.

Тестовые контакты использовались только в локальной базе и не включены в исходники или публикацию. Реальные CRM/рассылки не подключались.

## Компактная версия

- Chrome: 320 × 740, 390 × 844, 768 × 1024 и 1280 × 720.
- Все четыре переключателя видны одновременно, размер области нажатия — 44 px.
- Шапка остаётся сверху при прокрутке; выбор любого сервиса из нижней части страницы открывает его детали под шапкой.
- Клавиши со стрелками переключают сервис; выбор отражается в адресе и в форме.
- Дополнительные экраны раскрываются без переполнения страницы.
- Прямая ссылка `?service=projects` открывает нужный раздел.
- Ошибок JavaScript в проверенных сценариях нет.

## Адаптация GitHub Pages

Подготовлена отдельная статическая сборка без изменения дизайна. Проверены пути под `/frents-conference/`, загрузка оригинальных изображений/логотипа/шрифтов, параметр выбранного сервиса, ссылки бонусов и отсутствие переполнения на телефоне. Контракт внешнего POST проверен с имитацией ответа сервера; это не проверка приёма реальной заявки через публичный сервер.
