# Frents — конференционный лендинг

Лендинг для декораторов, студий аренды и команд событий. Шесть направлений, демонстрационные интерфейсы, отдельный блок мобильного приложения и сбор сегментированных заявок.

## Запуск

Node.js ≥22.13.0.

```sh
npm ci
npm run dev
```

Локальный сайт: http://localhost:5173. Сборка: `npm run build`.

## Что реализовано

- Одна страница с шестью сервисами и закреплённым переключателем: все направления видны без горизонтальной прокрутки даже на телефоне.
- Компактный первый экран, карточки 2 × 3 на телефоне, переключатель 3 × 2, детали и основной макет по выбранному сервису. Дополнительные возможности и экраны раскрываются по нажатию.
- Прокат; дизайн-проекты; складской учёт; B2B-маркет для поставщиков; барахолка с намерением продать/купить; специалисты с намерением найти команду/предложить услуги.
- Маркет и складской учёт отмечены как сервисы в разработке. Для них форма собирает интерес к запуску и не обещает готовый доступ.
- 6 основных макетов, последовательности демонстрационных экранов, 2 макета мобильного приложения.
- Настоящие ссылки на Frents в App Store и Google Play.
- Одна форма с несколькими интересами, именем, контактом и отдельным согласием.
- Серверная валидация, защита от повторной отправки, honeypot, ограничение повторов одного контакта и обработка недоступности хранилища.
- Заявки сохраняются в D1. Контакты не остаются в браузерном хранилище. Публичного API чтения заявок нет.
- После успешной отправки доступны 4 готовых материала, которые можно распечатать или сохранить в PDF.
- UTM и `source` сохраняются в заявке. Параметр `service` открывает нужное направление.
- Поддержка клавиатуры, reduced motion, мобильного меню и закреплённого мобильного CTA.

## Контент и дизайн

- `lib/services.ts` — тексты, преимущества, офферы и CTA шести сервисов.
- `components/conference-landing.tsx` — общая структура страниц и лид-форма.
- `components/app-showcase.tsx` — мобильные макеты и дополнительные экраны.
- `app/globals.css` — визуальная система; `app/compact.css` — компактная адаптивная компоновка для телефонов и небольших ноутбуков.
- `public/assets` — оригинальный логотип и шрифты Frents, предметные изображения и сгенерированная фотография.
- `public/bonuses` — материалы конференции.
- `docs/funnels.md` — портреты аудитории и логика воронок.
- `docs/content-status.md` — подтверждённые факты и то, что нужно заменить/утвердить.

Фирменный код взят с frents.ru: Montserrat Regular / Medium / SemiBold / Bold, зелёный `#83C100`, hover `#6BA300`, светлый зелёный `#F0F9E0`, текст `#1A1A1A` / `#5B5C5E`, границы `#E4E4E4`, кнопки со скруглением 10 px. Файлы локальные.

## Заявки

`POST /api/leads` записывает имя, контакт, направления, намерения, источник, UTM, версию согласия и время. Адрес посетителя хранится только как хеш для ограничения частоты. У каждого запроса UUID: повтор с тем же UUID и контактом не создаёт дубликат.

Таблица: `leads`, схема: `db/schema.ts`. Доступ владельца к данным — через инструменты базы Sites. Для продакшена также можно подключить существующий backend Frents вместо D1, сохранив контракт формы. CRM и рассылки не подключены.

Локальная база использует `.wrangler/state` (игнорируется Git). После первой сборки применить миграцию:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_polite_joystick.sql
```

Не применять один и тот же файл повторно к уже инициализированной базе. Миграции публикации управляются Sites.

## Сборка для GitHub Pages

```sh
npm run build:pages
```

Готовые статические файлы: `pages-dist/` (игнорируются Git в основной ветке). Они публикуются отдельной веткой `codex/github-pages`. Исходный React-компонент общий для обеих сборок.

В сборке Pages все изображения, шрифты и бонусы используют префикс `/frents-conference/`. Контактная форма обращается к публичному серверу `https://frents-conference.ameli-aniri.chatgpt.site/api/leads`; GitHub Pages сам не выполняет серверный код. На сервере разрешён CORS только для `https://serviceameli.github.io` и собственного домена. Читать заявки через публичный сайт нельзя: доступ к базе есть у владельца через Sites.


## Барахолка — раздел основного лендинга

Одна общая страница Барахолки открывается через переключатель сервисов по `/?service=market#service-details` и по сохранённому адресу `/baraholka/` (на GitHub Pages — под `/frents-conference/`). Оба адреса используют `ConferenceLanding`: прежнюю шапку и карточки с шестью сервисами, новый контент Барахолки, оригинальный блок приложения «Вся работа. В вашем кармане», бонус конференции и FAQ.

- Общий каркас, переключение сервисов и форма бонуса: `components/conference-landing.tsx`.
- Контент Барахолки: `components/flea-landing.tsx` и `components/flea-landing.css`; размеры текста, кнопки и отступы согласованы с основной страницей.
- Next/Vinext: `app/page.tsx` и `app/baraholka/page.tsx`.
- GitHub Pages: входы `github-pages/index.html` и `github-pages/baraholka/index.html`.
- Изображения вымышленных объявлений: `public/assets/frents-products-atlas.jpg`. Цены и города демонстрационные.
- CTA ведут в действующую Барахолку FRENTS и её единый вход по телефону. Форма бонуса сохраняет существующее подключение к API.
- Условия: размещение бесплатно до конца 2026 года; позднее возможны ограничения числа активных объявлений.

Сборка: `npm run build:pages`. Публикуется содержимое `pages-dist/` в существующую ветку `codex/github-pages`.
